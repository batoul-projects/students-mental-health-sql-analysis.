# 🧠 Analyzing Students' Mental Health (SQL Analysis)

## 📌 Project Overview
This project analyzes data from an international university to examine how the length of stay and acculturative stress affect the mental health of international students.

---

## 📊 Key Questions Addressed
- How does the length of stay (`length_of_stay`) impact diagnostic scores for depression (`todep`), anxiety (`toas`), and stress (`scs`)?
- What are the average health metric trends for international students versus domestic students?

---

## 🛠️ Tools & Technologies
- **Database / Language:** `SQL` (`PostgreSQL`)
- **Environment:** `DataLab` / `Jupyter Notebook`

---

## 📈 Key Findings
- Students with longer stay durations tend to show varying levels of diagnostic scores.
- SQL aggregation functions (`AVG`, `ROUND`, `GROUP BY`) were heavily utilized to extract actionable statistical insights.

---

## 📂 Project Structure
- `notebook.ipynb`: The complete SQL queries and analysis workbook.
